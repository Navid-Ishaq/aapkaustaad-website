## Prepare the DEV draft

1. Open DEVTO-READY-TO-PASTE.txt and paste its contents into DEV's Markdown editor. The proposed title, description and four tags are in the front matter; published is false.
2. Upload each of the eight PNGs with the editor's image upload control. Replace its matching UPLOAD_IMAGE_... placeholder with the URL returned by DEV. Local image paths will not upload themselves.
3. Preview the draft: check all eight images, captions, tables and code blocks. Keep the screenshot privacy note. Keep the distinction between local tests and user-reported live behavior.
4. Edit the title/author credit as desired, then publish only when ready. This package has not been posted or uploaded to DEV.
